# Visión

## Problema

Un CV tradicional presenta antecedentes, pero comunica con dificultad la combinación de capacidades, trabajos, proyectos propios y formas concretas de colaboración de un perfil multidisciplinario. Además, recrear cada nueva landing desde cero desperdicia decisiones ya resueltas.

## Propósito

El sitio de Pedro debe permitir que una persona comprenda rápidamente quién es, qué problemas técnicos y operativos puede convertir en soluciones concretas, qué evidencia existe y cómo contactarlo. Ingeniería, productos digitales y prototipado se entienden como expresiones de una misma forma de observar, diagnosticar, diseñar, implementar y mejorar. Debe crecer como una presencia profesional viva, no como un documento estático trasladado a HTML.

## Visión futura

El sitio 001 funcionará como caso de aprendizaje para una futura plataforma de landing pages y micrositios. La plataforma no se diseña todavía: primero se observará qué estructuras sobreviven al contenido real y a un segundo caso distinto.

## Principios arquitectónicos

1. El contenido es independiente de la presentación.
2. Los bloques tienen responsabilidades claras y pueden evolucionar por separado.
3. La estructura acepta diferentes áreas, tipos de trabajo y proyectos.
4. La accesibilidad, el rendimiento y el diseño responsive son requisitos base.
5. La complejidad se incorpora únicamente cuando dos o más casos reales la justifican.

## Deliberadamente fuera de v0.1

CMS, panel administrativo, autenticación, usuarios, base de datos, editor visual, backend, pagos, analítica, infraestructura SaaS y sistema complejo de componentes.
